# **App Name**: Kolkata Metro Guide

## Core Features:

- Station Search: Home screen with 'From Station' and 'To Station' input fields with autocomplete suggestions.
- Route Display: Route finder screen to display the optimal route between two stations.
- Route Calculation: Calculates the shortest path between two metro stations using a BFS or Dijkstra algorithm.
- Fare Calculation: Fare calculator to determine the fare between two stations.
- Station Info Display: Displays detailed information about a selected metro station, including timings, facilities, and platform details.
- Metro Map: Displays a zoomable and pannable image of the Kolkata metro map.
- Localization: Supports both English and Bengali languages for all text content.

## Style Guidelines:

- Primary color: Deep blue (#00308F) inspired by the Kolkata Metro's branding, conveying trust and reliability.
- Background color: Light blue (#E6EEFF), a desaturated version of the primary color, to provide a calming and accessible user experience.
- Accent color: Yellow-gold (#FFB300), analogous to the blue but with significantly greater brightness, for important interactive elements.
- Body and headline font: 'PT Sans', a modern and readable humanist sans-serif font that will work in both English and Bengali.
- Use clear, consistent icons from Material Design to represent station facilities and other app functions.
- Implement a Material 3-based layout with a bottom navigation bar for Home, Map, and Settings.
